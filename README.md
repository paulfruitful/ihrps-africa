# International Human Rights Protection Service (West African Chapter)

Official web interface for the **International Human Rights Protection Service (IHRPS — West African Chapter)**.

## Features
- **Minimalist Centered Logo & Circle Preloader** with automatic transition
- **Proportional Executive Hero** & **Trusted Partners Infinite Marquee Slider** (*UN Human Rights, Amnesty, Human Rights Watch, ECOWAS Court, NHRC*)
- **High-Resolution Local Visual Assets** (`/assets/`)
- **Zero-Config Vercel Deployment** (`vercel.json` with `cleanUrls: true`)
